# Gewichtsprijs eerst, anders per stuk (2026-10-11, gebruiker)

"Uiteindelijk gaat het mij om gewichtprijs." Vergelijken op prijs per kg of liter; zonder gewicht per stuk, **niet
weghalen** (een weglaat-versie met ~1800 stuk-aanbiedingen is teruggedraaid, revert in git). Per-stuk-vergelijking
alleen in families waar dat zinvol is (brood, broodjes, eieren, groente en fruit). Grove categorieën zijn prima:
"komkommer is komkommer".
